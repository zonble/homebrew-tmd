# homebrew-tmd

Official Homebrew tap for [TmdSwift](https://github.com/zonble/TmdSwift) (`tmd`).

## Installation

```bash
brew tap zonble/tmd
brew install tmd
```

## Documentation

See the [TmdSwift Repository](https://github.com/zonble/TmdSwift) for usage, examples, language specification, and AI skill integration.
